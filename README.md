## 💡 Projects I'm Proud Of

### 🔎 RAG Evaluation Framework
An evaluation framework for Retrieval-Augmented Generation systems.

- Measuring retrieval quality using Hit Rate and MRR.
- Evaluating answer quality and hallucination rates.
- Comparing different LLM and embedding providers.

**Stack:** Python · LangChain · DeepEval · LLMs

### 🏃 Marathon Photo Retrieval System
An intelligent computer vision application that helps marathon runners find their photos.

- Automatic bib number recognition.
- Computer Vision and OCR integration.
- Image-based retrieval.

**Stack:** Python · OpenCV · YOLO · PyTorch · OCR

### 🧠 Intelligent Incident Search
A semantic search system designed to find similar incidents and suggest relevant solutions.

- Multilingual semantic search using embeddings.
- Incident priority and category prediction.
- Automated ML pipelines and API integration.

**Stack:** Python · Sentence Transformers · FastAPI · MLflow · Airflow
